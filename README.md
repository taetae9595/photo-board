# 📸 우리 사진 보드 (패들렛형 사진 공유 + A4 모아찍기)

링크만 알면 누구나 사진을 올리고, 관리자는 원하는 사진만 골라 **A4 1장에 1·2·4·6장씩** 깔끔하게 인쇄하는 웹앱입니다.
순수 HTML/CSS/JS 라서 빌드 없이 GitHub Pages 에 그대로 올려 씁니다.

- 주소: https://taetae9595.github.io/photo-board/
- 저장: 기존 가족 앱과 같은 Supabase 프로젝트 (`tuejokazctxejnpjmwwt.supabase.co`)

---

## 1. 쓰는 사람(참여자)

1. 링크를 열고 **＋ 사진 올리기**를 누릅니다.
2. 사진을 고르거나 끌어다 놓습니다. **한 번에 여러 장**도 됩니다.
3. **작성자 이름**(필수)과 **한 줄 메모**(선택)를 적고 **올리기**를 누릅니다.
   - 이름은 이 브라우저에 기억되어 다음에 자동으로 채워집니다.
   - 고른 사진 모두에 같은 이름·메모가 붙습니다. 사진마다 다르게 남기려면 나눠서 올리세요.
4. 사진을 누르면 크게 볼 수 있고, ←/→ 로 넘길 수 있습니다.

사진은 올릴 때 브라우저에서 자동으로 줄여집니다(긴 변 최대 1400px, JPEG 0.82 → 보통 150~300KB).
아주 큰 원본(25MB 초과)이나 HEIC 처럼 브라우저가 못 읽는 형식은 올라가지 않습니다.

## 2. 관리자(선생님·주최자)

1. 오른쪽 위 **🔒 관리자** → 비밀번호 입력 → **들어가기**
   - 비밀번호는 **가족 앱과 같은 비밀번호**입니다(코드에 들어 있지 않고 서버에서 확인합니다).
   - 새로고침해도 이 탭에서는 관리자 상태가 유지됩니다(탭을 닫으면 다시 물어봅니다).
2. 관리자 모드에서는 카드를 **누르면 선택**(초록 체크)됩니다. 카드 왼쪽 위 아이콘으로 크게 보기 / 한 장 삭제.
3. 아래 **선택 바**에서
   - **인쇄** : 인쇄 설정을 열고
   - **선택 삭제** : 고른 사진을 한꺼번에 삭제
   - **선택 해제** : 선택을 모두 풉니다.
4. **나가기**를 누르면 관리자 모드가 풀립니다.

### 인쇄 설정

| 고르는 것 | 뜻 |
|---|---|
| 1장씩 | 사진 한 장이 A4 한 장 (4장 고르면 4장 인쇄) |
| 2장씩 | 한 장에 2장 (4장 고르면 2장 인쇄) |
| 4장씩 | 한 장에 4장 (4장 고르면 1장 인쇄) |
| 6장씩 | 한 장에 6장 (2×3) |

- **작성자 이름 표시** : 끄면 사진만 나옵니다.
- **사진 꽉 채우기** : 끄면(기본) 사진이 잘리지 않고 전체가 나옵니다(`contain`). 켜면 칸을 꽉 채우고 넘치는 부분은 잘립니다(`cover`).
- **첫 장 미리보기** 로 실제 종이에 어떻게 나올지 먼저 확인할 수 있습니다.
- **인쇄하기 · PDF 저장** → 브라우저 인쇄창이 열립니다.
  - 프린터를 고르거나, 목적지에서 **PDF로 저장**을 고르면 파일로 받을 수 있습니다.
  - **용지 크기 A4, 여백 없음(없음/0)**, **배율 100%(기본)** 로 두세요. 배율을 줄이면 여백이 생깁니다.
  - 인쇄물에는 화면의 버튼·툴바가 나오지 않고 고른 사진만 나옵니다.

인쇄 CSS 는 `@page { size: A4 portrait; margin: 0 }` + 페이지마다 `.sheet`(210mm × 296.8mm) 로 짜여 있어,
1·2·4·6장 어느 쪽을 골라도 사진이 페이지 경계에서 잘리거나 빈 장이 끼지 않습니다.

## 3. 처음 한 번만: 서버 준비

`supabase-setup.sql` 을 Supabase 대시보드 → SQL Editor 에 붙여넣고 **RUN** 하면 끝입니다.

- 만들어지는 것: `public.photo_board_posts` 표, 관리자 확인 함수 `photo_board_unlock`,
  삭제 함수 `photo_board_delete_post`(한 장) / `photo_board_delete_posts`(여러 장)
- 관리자를 확인할 때는 **이미 있는** `private.family_secrets`(`family_id = 'family'`)의 bcrypt 해시와
  비교합니다. 그래서 **비밀번호를 새로 정하거나 코드에 적을 필요가 없습니다.**
  (family-calendar 의 `supabase-setup.sql` 이 먼저 적용되어 있어야 합니다.)
- 권한: 누구나 읽기·올리기만. 삭제는 비밀번호를 통과한 RPC 로만 가능합니다.

표를 만들기 전에도 화면은 열립니다. 이때는 **체험 모드** 배너가 뜨고 사진이 이 브라우저에만 저장됩니다
(인쇄·선택 삭제 연습용). 표를 만들고 새로고침하면 실제 공유 모드로 바뀝니다.

## 6. 보안·개인정보 메모

- 사진을 올리면 **링크를 아는 사람은 누구나 볼 수 있습니다**(공개 페이지). 학교 사진이라면 얼굴·이름 노출 범위를 한 번 확인하세요.
- 관리자 비밀번호는 코드·SQL·README 어디에도 적지 않았습니다.
- 삭제는 서버에서 비밀번호를 확인한 뒤에만 됩니다. 표에 직접 삭제 권한은 주지 않았습니다.
- 이름·메모는 사진과 함께 서버에 저장됩니다. 지우면 서버에서도 지워집니다.

## 7. 자주 있는 문제

- **사진이 안 올라가요** → 25MB 가 넘거나 HEIC 형식일 수 있습니다. 휴대폰에서 공유할 때는 JPEG 로 변환해 주세요.
- **관리자 비밀번호가 틀렸다고 나와요** → 가족 앱(달력·책장)과 같은 비밀번호입니다. 띄어쓰기 없이 입력해 주세요.
- **인쇄가 두 장씩 나와요** → 인쇄창에서 여백이 '기본'으로 되어 있을 수 있습니다. 여백 '없음', 배율 100% 로 바꿔 주세요.
- **폰에서 옛 화면이 보여요** → 새로고침(또는 탭 닫고 다시 열기) 해 주세요.
